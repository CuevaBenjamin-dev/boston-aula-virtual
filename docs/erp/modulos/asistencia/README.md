# Asistencia — índice del módulo

El ERP conserva el expediente oficial diario, el calendario, las justificaciones y las salidas. Aula presenta la vista del docente y del estudiante y sus avisos; Identidad mantiene las cuentas. El alcance aprobado está en el paquete `PAQUETE_CODEX_ASISTENCIA_BBS` entregado el 26/11/2026. La exportación íntegra de MODULA revisión 532 no se encontró en el repositorio; no se asignan identificadores RF/RN inventados.
