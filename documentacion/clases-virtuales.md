# Clases virtuales

Una clase académica posee horario y tema. Cada enlace nuevo crea un `bloques_zoom` con número creciente, marca temporal y actor. El frontend refresca los datos periódicamente y muestra el último enlace. Son enlaces pegados por el docente; no hay API ni OAuth de Zoom. Desactivar `clases_y_grabaciones` bloquea las operaciones académicas y oculta las entradas del menú sin borrar registros.
